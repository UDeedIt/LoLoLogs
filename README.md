# LoLo Logs 🪵

CI
Kotlin
Maven Central

> A lightweight, high-performance and KMP-ready Kotlin logging library featuring structured logging, Flow integration, and zero-allocation performance, built for the D2D ecosystem to make cross-platform debugging effortless.

## Features

* Kotlin Multiplatform (KMP) Ready: Native support for Android, iOS, JVM, and more.
* Zero-Allocation: Designed to minimize garbage collection overhead during high-frequency logging.
* Flow Integration: Observe your logs in real-time using Kotlin Flows.
* Structured Logging: Easily attach metadata, tags, and payloads to your logs.
* Extensible: Create custom log destinations (Console, File, Crashlytics, etc.).
